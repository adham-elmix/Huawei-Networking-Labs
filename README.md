# 🌐 Huawei Networking Lab Portfolio

Welcome to my professional networking lab portfolio.  
This repository showcases hands-on projects built using Huawei eNSP, focusing on real-world network design, configuration, security, and troubleshooting.

Each lab simulates practical enterprise scenarios and demonstrates my ability to build, configure, and validate modern network infrastructures.

---

## 🚀 Labs Overview

### 🔹 Lab 01 — Basic Connectivity & Ping Test
**Objective:**  
Establish connectivity between end devices using proper IP addressing and verify communication using Ping.

**Key Highlights:**
- Configured PCs with valid IP addresses and subnet masks  
- Built a simple Layer 2 topology using a switch  
- Verified successful communication using Ping  

📁 Folder: `/Lab-01-Basic-Connectivity`

---

### 🔹 Lab 02 — Device Security & AAA Authentication
**Objective:**  
Secure device access using AAA authentication and local user configuration.

**Key Highlights:**
- Configured AAA authentication  
- Created local users with privilege levels  
- Protected device access from unauthorized users  

📁 Folder: `/Lab-02-Authentication-AAA`

---

### 🔹 Lab 03 — Router Configuration & Subnetting
**Objective:**  
Enable communication across multiple networks by configuring router interfaces and applying subnetting.

**Key Highlights:**
- Configured multiple router interfaces  
- Implemented subnet-based network segmentation  
- Enabled inter-network communication  

📁 Folder: `/Lab-03-Router-Subnetting`

---

### 🔹 Lab 04 — Link Aggregation (Eth-Trunk)
**Objective:**  
Improve network performance and redundancy by combining multiple physical links.

**Key Highlights:**
- Configured Eth-Trunk between switches  
- Achieved redundancy and load balancing  
- Increased bandwidth efficiency  

📁 Folder: `/Lab-04-EtherChannel-EthTrunk`

## 🖼️ Lab Structure
